# Milton Santos — vida e trajetória

Página interativa sobre a vida e a trajetória profissional do geógrafo Milton Santos (1926–2001).

- Abertura com retrato e um resumo da sua vida
- Mapa-múndi com os lugares onde viveu e trabalhou (dados cartográficos: Natural Earth, domínio público)
- Linha do tempo com cartões que viram ao clicar
- Bibliografia essencial

Site estático, sem build: basta abrir `index.html`. Publicado com GitHub Pages a partir da branch `main`.

## Capas dos livros

Para mostrar a capa de um livro, adicione a imagem em `capas/<id>.jpg` e preencha o campo `capa` do livro correspondente na lista `BOOKS`, dentro de `index.html`.
